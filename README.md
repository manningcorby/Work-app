# Work app

Phone and desktop version of the Work tracker. Logs sessions to the WORK sheet and runs the day plan from Second Brain, through the same Apps Script as the Chrome extension.

Open https://manningcorby.github.io/Work-app/ and add it to your home screen. On first open it asks for the Apps Script `/exec` link; that link is stored only on the device.

Built from the extension's popup code (see `build.py` in the source bundle). App version is in `index.html` (`app-version`).
